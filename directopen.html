Help / compatibility

Use this page on the target device. The app must be installed. Accept the browser’s Open app prompt if shown. On Android, try another variant if needed.

System settings links may be blocked. iOS has no supported general Settings link for websites. This page cannot confirm whether an app opened.

Stock apps vary by device and region. Only built-in, first-party or manufacturer-supplied apps are listed.

Local file links work only where the browser allows them. They cannot bypass storage permissions. If blocked, open your device’s Files app or File Explorer directly.
